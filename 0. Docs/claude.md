# 0. Docs - Claude Code 참고 문서

## 목적
Claude Code로 Obsidian vault를 운영할 때 필요한 참고 문서를 보관하는 폴더.

## 어떤 노트가 들어가는가
- Claude Code 사용법, 프롬프트 가이드
- Obsidian + Claude 연동 워크플로우 문서
- 폴더 구조 설계 문서, 운영 규칙 정리
- 자동화 설정 및 설정 변경 이력

## 작업 방식과 규칙
- 이 폴더의 문서는 vault 운영의 "매뉴얼" 역할
- 노트 작성용이 아닌 시스템 운영 참고용
- 구조나 규칙이 변경되면 이 폴더의 문서도 함께 갱신
