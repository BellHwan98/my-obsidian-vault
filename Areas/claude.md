# Areas - 지속적 관리 영역

## 목적
마감일 없이 지속적으로 관리해야 하는 책임 영역. 끝나지 않고 일정 수준을 유지해야 하는 영역을 다룬다.

## 어떤 노트가 들어가는가
- 영역별 하위 폴더 (예: `English/`, `건강/`, `재정/`, `커리어/`)
- 각 영역의 현재 상태, 목표, 루틴, 기준을 기록하는 노트
- 일기, 회고, 주간/월간 리뷰 노트

## 작업 방식과 규칙
- 영역은 역할 또는 책임 단위로 구분 (학생, 연구자, 영어 학습자 등)
- 영역 내 특정 목표가 마감일을 갖게 되면 → `Projects/`에 프로젝트로 분리
- 더 이상 관리하지 않는 영역 → `Archive/`로 이동
- 영역에서 얻은 지식은 Zettelkasten으로 분리하여 영구 보관
- 영역 노트는 "현재 상태와 방향"에 집중, 지식 축적은 Zettelkasten에서
