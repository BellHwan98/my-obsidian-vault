# Attachments - 첨부 파일

## 목적
노트에서 참조하는 이미지, PDF, 문서 등 비(非)마크다운 파일을 저장하는 폴더.

## 어떤 파일이 들어가는가
- 스크린샷 및 캡처 이미지 (PNG, JPG, HEIC)
- PDF 문서 (논문, 발표자료, 가이드)
- 다이어그램, 도표, Excalidraw 파일
- 기타 첨부 파일

## 작업 방식과 규칙
- Obsidian 설정에서 첨부 파일 경로를 이 폴더로 지정할 것
- 노트에서 `![[파일명]]`으로 임베드하여 참조
- 파일명: 자동 생성 형식 `Pasted image YYYYMMDDHHMMSS.png` 허용
- 의미 있는 파일은 설명적 이름으로 변경 권장
- 어떤 노트에서도 참조하지 않는 고아 파일은 주기적으로 정리
