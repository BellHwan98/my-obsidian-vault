# Projects - 프로젝트 작업대

## 목적
마감일이 있는 구체적인 프로젝트를 관리하는 폴더. 명확한 완료 조건과 기한이 존재하는 작업만 이곳에 둔다.

## 어떤 노트가 들어가는가
- 프로젝트별 하위 폴더 (예: `졸업논문 제출/`, `IELTS 시험 준비/`)
- 각 프로젝트 폴더 안에: 계획서, 진행 노트, 체크리스트, 회의록
- 프로젝트와 직접 관련된 참고자료 링크 (원본은 Resources 또는 Zettelkasten에 보관)

## 작업 방식과 규칙
- 프로젝트 폴더명: `프로젝트명/` (간결하게)
- 프로젝트가 완료되면 → `Archive/`로 폴더째 이동
- 프로젝트가 마감 없이 지속되면 → `Areas/`로 이동
- 하나의 프로젝트 = 하나의 하위 폴더
- 지식 자체는 여기 저장하지 않음 → Zettelkasten에 영구 노트로 분리
- 프로젝트 노트에서 Zettelkasten 노트를 `[[]]`로 참조
