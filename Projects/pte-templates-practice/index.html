WE / SWT / SST (타이핑): 모듈 정보와 변수값만 보이고 영어 본문을 처음부터 끝까지 정확히 입력해야 통과. WE는 단락 1~4를 순서대로 입력.
DI / RL / SGD / RTS (말하기): 본인이 입으로 말한 뒤 "정답 보기" 로 확인 후 "맞음/틀림" 셀프체크.
