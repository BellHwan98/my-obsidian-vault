# Resources - 참고 자료

## 목적
관심 주제에 대한 참고 자료를 모아두는 폴더. 특정 프로젝트나 영역에 귀속되지 않는 범용 자료.

## 어떤 노트가 들어가는가
- 주제별 하위 폴더 (예: `통계학/`, `영양학/`, `프로그래밍/`, `호주 이민/`)
- 웹 클리핑, 강의 요약, 도구 사용법, 가이드
- 아직 Zettelkasten으로 정제되지 않은 수집 단계의 자료

## 작업 방식과 규칙
- 주제(Topic) 단위로 폴더 구성
- 자료를 읽고 자신의 언어로 정리했다면 → `Zettelkasten/20. Permanent/`에 영구 노트 생성
- 원천 자료(논문, 책, 영상)의 요약은 `Zettelkasten/10. Literature/`에도 기록 가능
- 더 이상 관심 없는 주제 → `Archive/`로 이동
- 프로젝트 전용 자료는 `Projects/` 해당 폴더에 보관
