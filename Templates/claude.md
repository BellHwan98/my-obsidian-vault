# Templates - 노트 템플릿

## 목적
일관된 노트 작성을 위한 템플릿 보관 폴더. Obsidian의 Templates 코어 플러그인과 연동된다.

## 어떤 노트가 들어가는가
- 기본 노트 템플릿 (날짜, 주제, 테그 헤더)
- 문헌 노트 템플릿 (Literature 전용)
- 영구 노트 템플릿 (Permanent 전용)
- 프로젝트 계획 템플릿
- 회의록 템플릿
- 일기/회고 템플릿

## 작업 방식과 규칙
- 템플릿 파일은 직접 편집하여 사용하지 않음 (삽입 전용)
- Obsidian에서 `Ctrl/Cmd + T`로 템플릿 삽입
- 템플릿 변수: `{{date: YYYY-MM-DD}}`, `{{time}}` 사용
- 새 유형의 노트를 반복 작성하게 되면 → 템플릿으로 만들어 여기에 저장
- Obsidian 설정에서 Templates 폴더를 이 경로로 지정할 것
