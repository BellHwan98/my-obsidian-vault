# 00. Inbox - 빠른 메모

## 목적
떠오르는 아이디어, 영감, 질문, 임시 메모를 빠르게 캡처하는 장소. 정리되지 않은 원석 상태의 생각을 담는다.

## 어떤 노트가 들어가는가
- 갑자기 떠오른 아이디어나 질문
- 대화, 강의, 영상에서 얻은 즉흥적 메모
- 아직 분류되지 않은 스크랩이나 메모
- 나중에 정리할 키워드, 문장, 인용구

## 작업 방식과 규칙
- **캡처는 빠르게, 정리는 나중에** → 형식에 얽매이지 않고 일단 기록
- 파일명: `YYYY-MM-DD 키워드.md` 또는 자유 형식
- 정기적으로(주 1회 이상) Inbox를 리뷰하여 처리:
  - 지식으로 발전 가능 → `10. Literature/` 또는 `20. Permanent/`로 정제
  - 프로젝트 관련 → `Projects/` 해당 폴더로 이동
  - 참고 자료 → `Resources/`로 이동
  - 가치 없음 → 삭제
- **Inbox가 비어있는 것이 이상적인 상태** (처리 완료 = 빈 Inbox)
