# 20. Permanent - 영구 지식

## 목적
자신의 언어로 정제된 최종 형태의 지식 노트. 시간이 지나도 가치가 유지되며, 다른 노트와 연결되어 지식 네트워크를 형성한다.

## 어떤 노트가 들어가는가
- 하나의 명확한 아이디어/개념/통찰을 담은 원자적(atomic) 노트
- Literature 노트에서 추출하여 자신의 관점으로 재구성한 지식
- 여러 출처를 종합한 통합적 이해
- 경험에서 도출한 원칙이나 패턴

## 작업 방식과 규칙
- **하나의 노트 = 하나의 아이디어** (한 노트에 여러 개념을 섞지 않음)
- **파일명:** 아이디어를 설명하는 명확한 제목 (예: `식이 패턴과 우울증의 양방향 관계.md`)
- **자신의 언어로 작성** → 원문 복사가 아닌 이해한 내용을 서술
- **반드시 다른 노트와 연결** → `[[관련 노트]]` 링크 필수
- 출처가 있다면 `10. Literature/`의 문헌 노트를 `[[]]`로 참조
- 영구 노트는 삭제하거나 Archive로 이동하지 않음 (지식은 영구적)
- 기존 영구 노트와 모순되면 → 기존 노트를 수정하거나 관계를 명시
