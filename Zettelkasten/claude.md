# Zettelkasten - 지식 발전소

## 목적
프로젝트와 독립적으로 존재하는 지식 네트워크. 시간이 지나도 가치가 유지되는 지식을 축적하고 연결하는 공간. PARA(프로젝트 작업대)와 완전히 분리하여 지식이 특정 프로젝트에 갇히지 않도록 한다.

## 구조
```
Zettelkasten/
├── 00. Inbox/      - 빠른 캡처, 아이디어 씨앗
├── 10. Literature/ - 원천 자료 요약 (논문, 책, 강의)
└── 20. Permanent/  - 자신의 언어로 정제된 영구 지식
```

## 핵심 원칙
- **하나의 노트 = 하나의 아이디어** (Atomicity)
- **자신의 언어로 작성** (원문 복사 금지)
- **노트 간 `[[]]` 링크로 연결** (고립된 노트 없이)
- **프로젝트가 끝나도 지식은 남는다** → Zettelkasten은 Archive로 가지 않음

## 작업 흐름
1. 아이디어/메모 → `00. Inbox/`에 빠르게 캡처
2. 원천 자료를 읽고 요약 → `10. Literature/`에 문헌 노트 작성
3. 문헌 노트에서 핵심 통찰 추출 → `20. Permanent/`에 영구 노트 작성
4. 영구 노트끼리 `[[]]`로 연결하여 지식 네트워크 확장
